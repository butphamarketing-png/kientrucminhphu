# Kiến trúc Minh Phú — Website clone

Website clone bố cục/nội dung/ảnh theo [kientrucminhphu.com](https://kientrucminhphu.com).

## Chạy local

```bash
cd C:\Users\Admin\Downloads\minhphu-web
npm install
npm run dev
```

Mở http://localhost:3000

Production:

```bash
npm run build
npm start
```

## Cấu trúc trang chủ

1. Header + menu sticky
2. Slideshow
3. Giới thiệu
4. 5 điểm nổi bật
5. Lĩnh vực hoạt động (6 dịch vụ)
6. Công trình tiêu biểu
7. Mẫu nhà phố / biệt thự (tabs)
8. Tin tức + form đăng ký tư vấn
9. Footer + nút nổi Zalo/Gọi/FB
